# Коробомер

Сервис быстрого подбора **квадратных и прямоугольных** картонных коробок под стандарты и ограничения Wildberries (FBS / FBW).

## Что делает

1. **Перебор укладок** (`src/lib/layout-enumerate.ts`) для всех форм:
   - канон Д×Ш×В / Ø×H; поворот: без / плоскость / любой;
   - плоские: **одна стопка** | **стопки 2/4/6/8** | **слои** (сетка × высота, без разделителя);
   - допуск **разделителя** между стопками (`allowDivider` + `maxDividerMm`) — модель подбирает толщину, не раздувает бока вкладышами;
   - snap к exact-паллету только при почти точном совпадении (± шаг округления);
   - score: паллет → пустоты → техдоступ → минимум разделителя.
2. **Результат** — лучшая укладка по score (коробка + 3D); до 3 альтернатив свёрнуто; каталог — близкие типовые.
3. Зазор на сторону (плотная / стандарт / пузырчатая / хрупкое); объём россыпи — вторично.
4. Лимиты WB и европаллет 1200×800.
5. **Техлимиты слоттера** (L≥240, H≥80, W+H≥280) помечают «Техдоступ» или «Самосбор».

## Запуск

```bash
npm install
npm run dev -- --port 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

Проверка логики:

```bash
npx tsx scripts/verify-sizing.ts
```
