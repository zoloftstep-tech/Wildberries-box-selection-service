# Коробомер

Сервис быстрого подбора **квадратных и прямоугольных** картонных коробок под стандарты и ограничения Wildberries (FBS / FBW).

## Что делает

1. **Перебор укладок** (`src/lib/layout-enumerate.ts`) для всех форм:
   - канон Д×Ш×В / Ø×H как положение по умолчанию;
   - поворот: без / только в плоскости (Д↔Ш) / любой (в т.ч. на бок);
   - 1…6 стопок/групп, паттерны `uniform` и `brick` (для rect/flat);
   - разделитель между стопками (`dividerMm`); высота по номиналу (объём опционально раздувает);
   - **вкладыши** (`allowVoidFill`): модель сама подбирает разделитель и прокладки по бокам / сверху-снизу в лимитах (`maxDividerMm` / `maxSideInsertMm` / `maxHeightInsertMm`), чтобы выйти на exact-паллет и техлимиты;
   - snap к exact-делителям европаллета (напр. 240×160 → 5×5);
   - score: паллет (exact предпочтителен) → пустоты → техдоступ → минимум вкладышей → поворот от канона.
2. **Эталон** — всегда 1 стопка/группа (даже при слабом паллете).
3. **Оптимальные** — кандидаты с покрытием европаллета **≥ 90%** (или exact); слабее в блок не попадают.
4. Каталог и custom считаются **от выбранной укладки** (по умолчанию эталон).
5. Зазор на сторону (плотная / стандарт / пузырчатая / хрупкое); объём россыпи — вторично.
6. Лимиты WB и европаллет 1200×800.
7. **Техлимиты слоттера** (L≥240, H≥80, W+H≥280) **не отсекают** варианты:
   помечают «Техдоступ» или «Самосбор · штанцформа».

## Запуск

```bash
npm install
npm run dev -- --port 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

Проверка логики:

```bash
npx tsx scripts/verify-sizing.ts
```

## Стек

Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui.

Логика: `src/lib/layout-enumerate.ts`, `src/lib/sizing.ts`, `src/lib/wb-limits.ts`, `src/lib/tech-access.ts`, `src/lib/box-catalog.ts`, `src/lib/euro-pallet.ts`.
