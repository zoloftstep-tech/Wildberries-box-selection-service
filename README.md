# Коробомер

Сервис быстрого подбора **квадратных и прямоугольных** картонных коробок под стандарты и ограничения Wildberries (FBS / FBW).

## Что делает

1. Считает габаритный блок товара:
   - стопка плоских единиц (например 100 пакетиков 150×105×1,5 мм);
   - цилиндр (например свеча Ø150 × 105 мм → коробка по диаметру);
   - прямоугольный штучный товар и сетка для нескольких штук.
2. Добавляет зазор на сторону (плотная / стандарт / пузырчатая / хрупкое).
3. Предлагает индивидуальный внутренний размер (округление до 5 мм) и ближайшие типовые коробки из каталога.
4. Проверяет каждую коробку по лимитам:
   - **FBW · короб:** сторона ≤ 80 см, сумма ≤ 160 см, вес &lt; 25 кг;
   - **FBW · монопаллета:** сторона ≤ 120 см, сумма ≤ 200 см;
   - **FBS · СЦ:** сторона ≤ 120 см, сумма ≤ 200 см;
   - **FBS · ПВЗ:** сумма сторон товара ≤ 140 см, сторона короба ≤ 80 см.

## Запуск

```bash
npm install
npm run dev -- --port 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Стек

Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui.

Логика лимитов и подбора: `src/lib/wb-limits.ts`, `src/lib/sizing.ts`, `src/lib/box-catalog.ts`.
